Data Flow — A Filtered Request

Example: user changes the warehouse filter on the Orders page.

  1. User interacts with the UI
    Selects a warehouse in FilterBar.vue. The change updates a shared ref inside composables/useFilters.js.
  2. Reactive watcher fires
    The active view (e.g. views/Orders.vue) watches the filter ref and calls its loadData() function.
  3. Centralized API client builds the request
    api.getOrders(filters) in client/src/api.js serializes filters to query params, skipping any value equal to 'all'.
  4. HTTP GET to FastAPI
    axios sends GET http://localhost:8001/api/orders?warehouse=...&category=...&status=...&month=.... CORS middleware permits the cross-origin request.
  5. Server filters in memory
    main.py passes the orders list through apply_filters() (warehouse / category / status) and filter_by_month() (which expands Q1–Q4 via QUARTER_MAP).
  6. Pydantic validates & serializes
    Each result is checked against the Order model; FastAPI returns the validated list as JSON.
  7. Vue updates raw refs
    Response replaces a raw ref like allOrders. Derived data lives in computed() properties (totals, status counts, chart series) which re-evaluate automatically.
  8. Template re-renders
    Vue's reactivity diff-updates the DOM. Tables, summary cards, and SVG charts reflect the new filter state.
